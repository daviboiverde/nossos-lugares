# Nossos Lugares

App do casal Juliana & Davi: lista de lugares para conhecer, notas por critério e números do que já viveram juntos.

- Site: https://daviboiverde.github.io/nossos-lugares/
- Instalação no iPhone: abrir no Safari → Compartilhar → Adicionar à Tela de Início.
- Os dados ficam só no celular (localStorage). Use **Ajustes → Fazer backup** para salvar uma cópia.
